## Design Context

### Users
Developers and small product teams setting up product events for their existing coding agent.

### Brand Personality
Calm, approachable, precise. Personality comes from the expressive Slurp wordmark and mascot.

### Aesthetic Direction
Use the archived landing page as the reference: pale-blue rail, white content, red branding, DM Sans headings, body text and labels (clean, soft, and approachable, matching the supplied workspace reference), Monaspace only for code and technical identifiers. Share the same language across public pages and private setup.

### Design Principles
- Put the next useful action before marketing copy in setup.
- Keep SDK, sync, agent and report instructions concrete and current.
- Use quiet borders, generous spacing and restrained brand accents.
- Preserve offline setup and private credential controls.
- Support keyboard navigation, readable contrast, narrow windows and reduced motion.
